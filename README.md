# ABTalks — 60 Days Coding Challenge

**Build your coding habit. Get discovered.**

A modern, full-stack platform for tracking coding progress and building accountability within a developer community. ABTalks is a 60-day challenge platform that transforms how developers learn and grow together.

## 🚀 What is ABTalks?

ABTalks is a gamified habit-tracking platform designed for developers who want to:
- Build consistent coding habits over 60 days
- Track daily progress with visual analytics
- Compete on leaderboards and gain recognition
- Connect with a supportive developer community
- Share achievements on social media

## ✨ Core Features

- **60-Day Challenge Tracking** — Complete daily coding tasks and maintain your streak
- **Progress Dashboard** — Visual heatmaps and stats showing your coding activity
- **Leaderboard System** — Compete globally and see where you stand
- **Community Hub** — Connect, share, and support fellow developers
- **Social Integration** — Share wins on Instagram, LinkedIn, YouTube, X, and Discord
- **Google Authentication** — Seamless sign-in and onboarding
- **Real-time Updates** — Live ticker showing community activity

## 🛠️ Tech Stack

- **Frontend**: Modern responsive UI with smooth animations
- **Backend**: Full-stack web application with authentication
- **Authentication**: Google Sign-In integration
- **Data**: Persistent user profiles and progress tracking
- **Hosting**: Production deployment at abtalks.in

## 🎯 Target Audience

- Aspiring developers starting their coding journey
- Self-taught programmers building consistency
- Coding bootcamp students staying accountable
- Career switchers committing to 60 days of learning
- Tech communities organizing group challenges

## 🌟 How It Works

1. **Sign In** — Connect with your Google account
2. **Join Challenge** — Commit to the 60-day coding journey
3. **Log Daily Tasks** — Track your coding progress each day
4. **Build Your Streak** — Maintain consistency and grow your streak count
5. **Climb Leaderboard** — Compete with peers and earn recognition
6. **Share & Celebrate** — Share achievements with your network

## 📊 Metrics Tracked

- **Daily Commits** — Number of coding tasks completed
- **Current Streak** — Consecutive days of coding
- **Total Completed** — Lifetime task completion count
- **Rank Position** — Your standing on the global leaderboard
- **Activity Heatmap** — 60-day visual progress calendar
